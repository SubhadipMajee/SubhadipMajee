* 🧠 AI skill extraction
* 📊 ATS-style job matching
* 🔎 Matched & missing skills analysis

* ✍️ AI resume optimization
* 📧 AI cold-email generation
* 🎯 Job filtering by role, location and type

`FastAPI` `React` `Groq` `Llama 3.3` `JSearch API`
